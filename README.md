# Meu Blog Azul

Um blog pessoal feito com HTML, CSS e JavaScript básicos. É um projeto para praticar a publicação de imagens e a criação de comentários.

## Como abrir

Abra o arquivo `index.html` em um navegador. Não é preciso instalar nada.

## Como usar

1. Preencha o título e a legenda.
2. Escolha uma imagem do seu dispositivo.
3. Clique em **Publicar imagem**.
4. Escreva um comentário no campo abaixo da publicação e clique em **Comentar**.

As publicações e os comentários ficam na página enquanto ela estiver aberta. Para guardar os dados após fechar ou atualizar a página, seria necessário adicionar armazenamento ou um servidor.

## Arquivos

- `index.html`: conteúdo e formulários da página.
- `style.css`: cores, espaçamento e layout.
- `script.js`: criação de publicações e comentários.
